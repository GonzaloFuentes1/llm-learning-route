Infraestructura & MLOps
Uso del Cluster HPC Básico
SSH, llaves públicas, VS Code Remote, rsync, htop, nvtop, nvidia-smi, tmux, SLURM y Git en el cluster.
MLOps: W&B + SLURM Core
Experiment tracking con Weights & Biases, logging de métricas y artefactos, scripts SLURM para entrenamiento y array jobs.
Datos
Tokenización en Cloud Core
Pipeline Datatrove, tokenización paralela a escala de TB, verificar cobertura del vocabulario en es/pt.
Filtrado de Calidad Core
Clasificadores fastText, filtro de perplejidad KenLM, reglas Gopher/C4 y pipeline completo con Datatrove.
Clasificador FineWeb-Edu Avanzado
Etiquetar calidad educativa con un LLM, entrenar un regresor XLM-R sobre esas etiquetas y correr inferencia masiva para filtrar corpus en es/pt.
JQL: filtrado multilingüe Avanzado Nuevo
Judging Quality across Languages: elegir LLM-jueces contra un gold set humano, destilarlos en cabezas livianas sobre embeddings multilingües y filtrar FineWeb2 es/pt por percentil.
Mid-training y annealing Avanzado Nuevo
Diseñar la fase final del pretraining: mezcla de datos de alto valor, decay del learning rate y cómo medir lo que aporta, siguiendo las recetas abiertas de 2025-2026.
Anonimización de PII Core
Remoción de datos personales con Presidio y spaCy: nombres, emails, RUT/CPF, teléfonos e IPs en es/pt.
Sequence Packing Core
Eliminar padding (~30-50% de tokens desperdiciados): greedy bin-packing, máscaras por documento y padding-free con HuggingFace.
Entrenamiento de Tokenizadores Avanzado
Entrenar BPE desde cero y extender el vocabulario de LLaMA 3 para español y portugués: fertility, embeddings para tokens nuevos y evaluación.
Pipeline Sintético con Reward Model Avanzado
Generar N respuestas, puntuar con un RM, filtrar por umbral, curriculum learning e iteración con el modelo mejorado. Detección de model collapse.
Arquitectura & Pretraining
Un LLM moderno desde cero Core Nuevo
Implementar en PyTorch el decoder que comparten Llama 3, Qwen3 y OLMo (RMSNorm, RoPE, GQA, SwiGLU, QK-norm) y entrenar un modelo pequeño en español.
MoE desde cero Avanzado Nuevo
Router top-k, expertos fine-grained y compartidos, colapso de expertos y balanceo con y sin auxiliary loss: la arquitectura por defecto de los modelos abiertos de 2026.
Reproducir una scaling law Avanzado Nuevo
Diseñar una grilla barata con WSD y cooldowns, ajustar Chinchilla por IsoFLOPs con intervalos de confianza y decidir tamaño y tokens para es/pt con evidencia propia.
Código de Entrenamiento Core
Loop de pretraining con accelerate y DeepSpeed ZeRO, gradient accumulation, bf16, checkpointing y cómo interpretar la loss curve.
FSDP2 y torchtitan Avanzado Nuevo
Entrenamiento distribuido PyTorch-nativo: fully_shard, checkpoints DCP, paralelismo 4D con torchtitan y lanzamiento multi-nodo en SLURM.
Continual Pretraining es/pt Avanzado
Adaptar un modelo base a español y portugués latinoamericano: mezcla de datos, prevención de catastrophic forgetting y evaluación intermedia.
Debugging de Entrenamiento Core
Loss spikes, gradient norms, OOM, NaN en gradientes y memory profiling con torch.profiler.
Post-training & Alineamiento
LoRA y QLoRA Core
Adaptar modelos abiertos a español/portugués con adaptadores de bajo rango: rank, módulos target y diagnóstico de convergencia.
Datasets SFT para Latam Avanzado
Datos de instrucción en español/portugués: Self-Instruct, Magpie, Evol-Instruct, filtrado por idioma y calidad, y publicación en HF Hub.
Alineamiento con DPO y variantes Core
DPO clásico, ORPO (sin reference model) y KTO (sin pares) con TRL: formato de datos y métricas de diagnóstico.
Reward Models Core
Entrenar un RM Bradley-Terry con TRL, best-of-N, delta filtering para DPO online y diagnóstico de reward hacking.
GRPO y RL para razonamiento Avanzado
El algoritmo de DeepSeek-R1 con GRPOTrainer: rewards verificables para matemáticas y código, y diagnóstico de colapso de reward.
Destilación de razonamiento Avanzado Nuevo
SFT con trazas largas (el cold start de R1-Distill, OpenThinker y s1): generar, filtrar y entrenar para que el modelo razone en español y portugués.
On-policy distillation Avanzado Nuevo
Señal densa por token sobre los rollouts del propio estudiante: transferir capacidades con mucho menos cómputo que RL y recuperar el chat tras continual pretraining.
RL agéntico con herramientas Avanzado Nuevo
SFT de tool calling y RL multi-turn: formato de herramientas, entornos que se puntúan solos y escalado a sandboxes.
Model merging con mergekit Core Nuevo
Model soups, SLERP, TIES/DARE y chat vectors: combinar un continual pretraining en español con un modelo instruct casi sin GPU.
Seguridad & Guardrails
Clasificadores de toxicidad con HarmBench Avanzado Nuevo
Behaviors de HarmBench adaptados a es/pt, etiquetado con el juez de HarmBench o un guard moderno, y destilación a un clasificador liviano para guardrails y filtrado de datos.
Red teaming y evaluación de seguridad Avanzado Nuevo
Pipeline HarmBench completo, StrongREJECT, over-refusal y ataques automatizados contra un endpoint vLLM, más sesgo social en español con SESGO.
Guardrails en producción con vLLM Core Nuevo
Defensa en profundidad: un guard multilingüe servido con vLLM antes y después del LLM, protección contra prompt injection y medición de latencia.
Toxicidad en datos de pretraining Avanzado Nuevo
Clasificadores de toxicidad por idioma para corpus web es/pt, cuánto filtrar sin perder controlabilidad, y HarmFormer como referencia.
Evaluación
Evaluación para español/portugués Core

Evaluación estadísticamente rigurosa Core Nuevo

Evaluación multilingüe con lighteval Core Nuevo
Tareas nativas en español y portugués, formulaciones cloze vs opción múltiple, tareas custom y PoETa v2 para portugués.
LLM-as-a-judge calibrado Avanzado Nuevo
Rúbricas, validación contra etiquetas humanas y corrección estadística del puntaje de un juez abierto servido en vLLM.
Inferencia & Deployment
Serving con vLLM: primeros pasos Básico

Serving en producción: vLLM V1 y SGLang Core Nuevo
Prefix caching, structured outputs, multi-LoRA, speculative decoding y benchmarking de TTFT/ITL con vllm bench y GuideLLM.
Cuantización para inferencia Core
FP8, INT4 (W4A16) y NVFP4 con llm-compressor para vLLM, GGUF con llama.cpp, y cómo medir calidad vs velocidad en es/pt.
Speculative Decoding Avanzado
2-3× más rápido sin degradar calidad: draft model, EAGLE-3 y MTP en vLLM, y benchmarking de tokens/s.
Aplicaciones: RAG, agentes y encoders
RAG en español y portugués Core Nuevo

Agentes con tool calling y MCP Avanzado Nuevo

Encoders para es/pt Core

Interpretabilidad
Interpretabilidad práctica Core Nuevo
