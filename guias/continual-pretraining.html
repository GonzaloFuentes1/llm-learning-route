Continual Pretraining: de LLaMA a español/portugués

Adapta un modelo base en inglés (LLaMA 3, Mistral) a español y portugués latinoamericano mediante continual pretraining. Cubre mixture de datos, prevención de catastrophic forgetting, configuración de entrenamiento y evaluación intermedia.

1. Continual pretraining vs fine-tuning

Continual PretrainingSFT / Fine-tuning
ObjetivoNext-token prediction (causal LM)Seguir instrucciones / formato de chat
Tokens entrenadosMiles de millones (1B–100B+)Millones (<1B)
Tipo de datosTexto plano, web crawl, librosPares instrucción-respuesta
LR típico1e-4 a 3e-51e-5 a 2e-4 (LoRA)
Cuándo usarloEl modelo base no entiende bien el idioma objetivoEl modelo ya entiende el idioma; solo necesita seguir instrucciones
¿Cuándo hacer continual pretraining? Si el modelo base fue entrenado con <5% de datos en español/portugués (ej. LLaMA 2), necesitas continual pretraining. Si el modelo ya tiene buena comprensión del idioma (ej. LLaMA 3 con 5%+ es/pt), a veces es suficiente con SFT + DPO.

2. Mixture de datos

La clave es no eliminar el inglés del training — eso causa catastrophic forgetting de las capacidades adquiridas en el pretraining original.

FuenteRatio recomendadoPor qué
Español (es-*) — web crawl filtrado35–45%Corpus principal para adaptar el idioma
Portugués (pt-BR) — web crawl filtrado20–25%Cobertura de variante latinoamericana
Inglés — alta calidad (FineWeb-Edu)20–30%Retiene capacidades del modelo original
Código (Python, SQL)5–10%Preserva razonamiento y capacidades técnicas
Datos curados (Wikipedia, libros)5–10%Conocimiento factual de alta densidad
python — data_mixture.py
from datasets import load_dataset, interleave_datasets

# Fuentes en JSONL (campo "text") y su proporción objetivo en la mezcla
SOURCES = {
    "es_web":    ("data/es_web_filtered/*.jsonl", 0.40),
    "pt_web":    ("data/pt_web_filtered/*.jsonl", 0.22),
    "en_edu":    ("data/fineweb_edu/*.jsonl",     0.25),
    "code":      ("data/starcoderdata/*.jsonl",   0.08),
    "wiki_espt": ("data/wiki_es_pt/*.jsonl",      0.05),
}

def load_source(name: str, pattern: str):
    ds = load_dataset("json", data_files=pattern, split="train")
    ds = ds.select_columns(["text"])  # mismas columnas en todas las fuentes
    return ds.map(lambda _: {"source": name})

datasets_, probs = [], []
for name, (pattern, weight) in SOURCES.items():
    datasets_.append(load_source(name, pattern))
    probs.append(weight)

# Cada documento se toma de la fuente i con probabilidad probs[i], así la
# mezcla respeta los ratios sin importar el tamaño de cada fuente.
# "first_exhausted" corta cuando se agota una fuente (sin repetir datos);
# "all_exhausted" sobremuestrea (repite) las fuentes chicas hasta agotar todas.
mixture = interleave_datasets(
    datasets_, probabilities=probs, seed=42, stopping_strategy="first_exhausted"
)

# Nota: los ratios son por documento. Para ratios por token, divide cada peso
# por el largo promedio (en tokens) de los documentos de esa fuente y renormaliza.
mixture.to_json("data/continual_pretrain_mixture.jsonl", force_ascii=False)
print(mixture.to_pandas()["source"].value_counts(normalize=True))

3. Configuración del entrenamiento

El continual pretraining usa el mismo loop que el pretraining estándar pero con ajustes específicos para evitar forgetting.

python — continual_pretrain.py
import os
from itertools import chain

import torch
from datasets import load_dataset
from transformers import (AutoModelForCausalLM, AutoTokenizer, Trainer,
                          TrainingArguments, default_data_collator)
from transformers.trainer_utils import get_last_checkpoint

# Llama 3.1 es gated: acepta la licencia en HF y exporta HF_TOKEN.
# Alternativa abierta sin gating: "Qwen/Qwen3-8B-Base".
BASE_MODEL  = "meta-llama/Llama-3.1-8B"  # modelo base (no-instruct)
OUTPUT_DIR  = "models/llamagpt-es-pt"
DATA_FILE   = "data/continual_pretrain_mixture.jsonl"
BLOCK_SIZE  = 4096

tokenizer = AutoTokenizer.from_pretrained(BASE_MODEL)
model = AutoModelForCausalLM.from_pretrained(
    BASE_MODEL,
    dtype=torch.bfloat16,
    attn_implementation="flash_attention_2",  # requiere flash-attn
)

dataset = load_dataset("json", data_files={"train": DATA_FILE}, split="train")
# Split held-out pequeño para evaluar durante el entrenamiento
splits = dataset.train_test_split(test_size=2000, seed=42)

def tokenize(examples):
    # Agrega EOS al final de cada documento para separarlos al empaquetar
    out = tokenizer(examples["text"])
    out["input_ids"] = [ids + [tokenizer.eos_token_id] for ids in out["input_ids"]]
    out["attention_mask"] = [m + [1] for m in out["attention_mask"]]
    return out

def group_texts(examples):
    # Packing: concatena y corta en bloques de BLOCK_SIZE (sin padding).
    # Ojo: sin máscara por documento hay atención entre documentos del mismo
    # bloque; para evitarlo usa DataCollatorWithFlattening (ver packing.html).
    concat = {k: list(chain(*examples[k])) for k in examples.keys()}
    total = (len(concat["input_ids"]) // BLOCK_SIZE) * BLOCK_SIZE
    result = {k: [v[i:i + BLOCK_SIZE] for i in range(0, total, BLOCK_SIZE)]
              for k, v in concat.items()}
    result["labels"] = [ids.copy() for ids in result["input_ids"]]
    return result

def prepare(ds):
    ds = ds.map(tokenize, batched=True, remove_columns=ds.column_names)
    return ds.map(group_texts, batched=True)

train_ds = prepare(splits["train"])
eval_ds  = prepare(splits["test"])

args = TrainingArguments(
    output_dir=OUTPUT_DIR,
    num_train_epochs=1,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=16,    # effective batch = 64 × num_gpus
    learning_rate=1e-4,                # ~3x menor que el pico original (3e-4)
    lr_scheduler_type="cosine",
    warmup_steps=500,                  # re-warmup desde 0
    weight_decay=0.1,
    bf16=True,
    gradient_checkpointing=True,
    logging_steps=50,
    save_steps=1000,
    eval_strategy="steps",
    eval_steps=500,
    dataloader_num_workers=4,
    report_to="wandb",
)

trainer = Trainer(
    model=model,
    args=args,
    train_dataset=train_ds,
    eval_dataset=eval_ds,
    data_collator=default_data_collator,  # bloques de largo fijo: no requiere pad_token
)

# Reanuda solo si ya existe un checkpoint (True falla en la primera corrida)
last_ckpt = get_last_checkpoint(OUTPUT_DIR) if os.path.isdir(OUTPUT_DIR) else None
trainer.train(resume_from_checkpoint=last_ckpt)
trainer.save_model(OUTPUT_DIR)
Learning rate crítico: usa un LR pico menor que el del pretraining original, típicamente 3–10x menor. LLaMA 3 8B fue entrenado con LR pico de 3e-4; para continual pretraining usa 1e-4 a 3e-5, con re-warmup y decaimiento cosine (Ibrahim et al., 2024). Un LR muy alto destruye los pesos originales; uno muy bajo apenas adapta el idioma.
Memorizar no es razonar: Li & Goyal (2025) muestran con el benchmark KUP que el continual pretraining logra memorizar hechos nuevos, pero los modelos casi no razonan con ellos (<2% en sondas indirectas). Su Memory Conditioned Training (MCT) mejora hasta 25.4% sobre el continual pretraining estándar. Si el objetivo es inyectar conocimiento regional (no solo idioma), evalúa también preguntas indirectas sobre ese conocimiento.

5. Evaluación durante el entrenamiento

Evalúa en ambos idiomas (es/pt y en) para detectar forgetting. Monitorea estos benchmarks (más detalle en Evaluación LatAm):

bash — eval_checkpoint.sh
#!/bin/bash
# Correr cada N pasos como SLURM job dependency
CKPT=$1
NAME=$(basename "$CKPT")

# Español: MGSM (CoT nativo) + Global-MMLU completo
lm_eval --model vllm \
  --model_args pretrained="$CKPT" \
  --tasks mgsm_native_cot_es,global_mmlu_full_es \
  --num_fewshot 5 \
  --output_path "eval_logs/${NAME}_es/"

# Inglés: verificar que no hay forgetting
lm_eval --model vllm \
  --model_args pretrained="$CKPT" \
  --tasks mmlu,arc_challenge \
  --num_fewshot 5 \
  --output_path "eval_logs/${NAME}_en/"

# Comparar con el modelo base (evaluado antes con --output_path eval_logs/base_en/).
# lm_eval escribe {dir}/{modelo}/results_{fecha}.json; compare_eval.py toma el más reciente
python compare_eval.py \
  --base   eval_logs/base_en/ \
  --tuned  "eval_logs/${NAME}_en/"
python — compare_eval.py
import argparse, glob, json, os

parser = argparse.ArgumentParser()
parser.add_argument("--base",  help="directorio --output_path del modelo base")
parser.add_argument("--tuned", help="directorio --output_path del checkpoint")
args = parser.parse_args()

def load_results(output_dir: str) -> dict:
    # lm_eval guarda {output_dir}/{modelo_sanitizado}/results_{fecha}.json
    files = glob.glob(os.path.join(output_dir, "**", "results_*.json"), recursive=True)
    if not files:
        raise FileNotFoundError(f"No hay results_*.json en {output_dir}")
    with open(max(files, key=os.path.getmtime)) as f:
        return json.load(f)["results"]

base, tuned = load_results(args.base), load_results(args.tuned)

print("Benchmark              Base    Tuned   Delta")
print("-" * 50)
for task in base:
    if task not in tuned:
        continue
    b = base[task].get("acc,none",  base[task].get("acc_norm,none",  0))
    t = tuned[task].get("acc,none", tuned[task].get("acc_norm,none", 0))
    delta = t - b
    flag = "⚠️ " if delta < -0.03 else "  "
    print(f"{flag}{task:22s} {b:.3f}  {t:.3f}  {delta:+.3f}")
Umbral de alarma: si cualquier benchmark en inglés cae más de 3 puntos porcentuales respecto al modelo base, hay forgetting significativo. Aumenta el ratio de replay en inglés y reduce el LR.
