Interpretabilidad práctica: logit lens, activation patching y steering

Las tres operaciones que sostienen casi toda la interpretabilidad mecanicista (leer capas intermedias, atribuir causalmente un comportamiento a componentes concretos e intervenir el residual stream) aplicadas a Qwen3 con nnsight y nnterp, con hechos latinoamericanos en español y portugués y vectores de steering de idioma (es→pt) y de registro (usted/tú). Sirve también para depurar checkpoints propios: en qué capa se resuelve un hecho y qué cambia tras un continual pretraining.

1. Modelo mental y herramientas

Un transformer decoder es una pila de bloques que leen y escriben sobre un mismo vector por token, el residual stream: cada capa suma la salida de su atención y de su MLP. Por eso las tres técnicas de esta guía se pueden expresar como operaciones sobre ese vector: leerlo en cada capa (logit lens), reemplazarlo por el de otra entrada y medir el efecto (activation patching) y sumarle una dirección (steering).

Elegimos Qwen3-1.7B-Base: es denso, no requiere aceptar licencia en HF, es multilingüe (español y portugués razonables para su tamaño) y tiene SAEs y transcoders públicos para seguir con técnicas más avanzadas. Usamos el modelo base y no el instruct para que los prompts sean continuaciones simples sin chat template.

python
import torch
from nnterp import StandardizedTransformer

MODEL_ID = "Qwen/Qwen3-1.7B-Base"        # en CPU: "Qwen/Qwen3-0.6B-Base"
DEVICE = "cuda" if torch.cuda.is_available() else "cpu"
if DEVICE == "cuda":
    DTYPE = torch.bfloat16 if torch.cuda.is_bf16_supported() else torch.float16  # T4 -> fp16
else:
    DTYPE = torch.float32

# StandardizedTransformer renombra la arquitectura al esquema de nnterp y la valida al cargar.
# Los kwargs extra pasan a from_pretrained (transformers v5 usa `dtype`, no `torch_dtype`).
model = StandardizedTransformer(MODEL_ID, dtype=DTYPE, device_map="auto")
print(f"capas={model.num_layers}  d_model={model.hidden_size}  vocab={model.vocab_size}")

# Sanity check: el logit lens de la ÚLTIMA capa (ln_final + lm_head sobre su salida)
# tiene que coincidir con los logits reales del modelo.
prompt = "La capital de Chile es"
with model.trace(prompt):
    # Orden del forward: primero la última capa y después los logits del modelo
    lens_last = model.project_on_vocab(model.layers_output[model.num_layers - 1]).save()
    final_logits = model.logits.save()

max_diff = (final_logits.float() - lens_last.float()).abs().max().item()
print(f"max |logits - lens(última capa)| = {max_diff:.4f}")   # ~0 salvo redondeo bf16

top = final_logits[0, -1].float().softmax(-1).topk(5)
for p, t in zip(top.values.tolist(), top.indices.tolist()):
    print(f"{model.tokenizer.decode(t)!r:14} {p:.3f}")
Todo lo que uses fuera del with necesita .save(). Dentro del bloque nnsight ejecuta el modelo real y tu código se intercala con el forward; además hay que acceder a los módulos en el orden del forward (capa 3 antes que capa 10, atención antes que MLP). Leer en desorden lanza un error de acceso fuera de orden (OutOfOrderError, subclase de MissedProviderError, en 0.7).

3. Logit lens en español y portugués

El logit lens aplica la norma final y el unembedding al residual stream de cada capa intermedia, como si el modelo terminara ahí. Graficando P(respuesta) por capa se ve en qué profundidad "aparece" un hecho. Usamos hechos latinoamericanos con el mismo contenido en es y pt para comparar ambos idiomas.

python
# Continúa el bloque anterior (usa `model`).
import pandas as pd
import plotly.express as px
from nnterp.interventions import logit_lens

FACTS = [  # (idioma, prompt, respuesta con espacio inicial)
    ("es", "La capital de Chile es", " Santiago"),
    ("pt", "A capital do Chile é", " Santiago"),
    ("es", "La capital de Colombia es", " Bogotá"),
    ("pt", "A capital da Colômbia é", " Bogotá"),
    ("es", "La capital de Uruguay es", " Montevideo"),
    ("pt", "A capital do Uruguai é", " Montevidéu"),
    ("es", "La moneda oficial de México es el", " peso"),
    ("pt", "A moeda oficial do Brasil é o", " real"),
    ("es", "El libertador de Argentina fue José de", " San"),
    ("pt", "O primeiro imperador do Brasil foi Dom", " Pedro"),
]   # amplíalo a ~50 prompts por idioma para curvas estables


def first_token(text: str) -> int:
    """Primer token de la respuesta: el logit lens mide solo el siguiente token."""
    return model.tokenizer.encode(text, add_special_tokens=False)[0]


probs = logit_lens(model, [p for _, p, _ in FACTS])   # (n_prompts, n_capas, vocab)

rows = []
for i, (lang, prompt, answer) in enumerate(FACTS):
    tid = first_token(answer)
    top1 = probs[i].argmax(-1)
    hits = (top1 == tid).nonzero().flatten().tolist()
    print(f"[{lang}] {prompt!r:45} top-1 desde la capa {hits[0] if hits else '—'}")
    for layer in range(probs.shape[1]):
        rows.append({"lang": lang, "prompt": prompt, "layer": layer,
                     "p_target": probs[i, layer, tid].item()})

df = pd.DataFrame(rows)
df.to_csv("logit_lens_es_pt.csv", index=False)
curve = df.groupby(["lang", "layer"], as_index=False)["p_target"].mean()
fig = px.line(curve, x="layer", y="p_target", color="lang",
              title=f"P(respuesta) por capa con logit lens: {MODEL_ID}")
fig.write_html("logit_lens_es_pt.html")
Mapa capa × posición del token top-1

La curva agregada esconde lo interesante. El mapa de top-1 por capa y posición muestra qué "piensa" el modelo en cada token: en modelos con mucho inglés en el pretraining suelen aparecer tokens en inglés en capas medias antes de la respuesta en español o portugués (el tema de la guía ¿En qué idioma piensa el modelo?).

Límites del logit lens: en capas tempranas el residual todavía no está en la base del unembedding y el lens da basura o tokens de la entrada; por eso el tuned lens entrena una traslación afín por capa. Patchscopes (nnterp.interventions.patchscope_lens) es otra alternativa: inyecta el estado oculto en un prompt objetivo y deja que el propio modelo lo describa. Y lo más importante: que un concepto sea decodificable en una capa no prueba que el modelo lo use; para eso está el patching.

4. Activation patching: causalidad capa × posición

Corremos un prompt limpio (por ejemplo "La capital de Chile es" → Santiago) y uno corrupto que solo difiere en el sujeto ("La capital de Perú es" → Lima); el código toma el primer par con igual número de tokens. Luego, en el run corrupto, reemplazamos la activación de una capa y una posición por la del run limpio y medimos cuánto se recupera la preferencia por la respuesta limpia. La métrica es el logit diff normalizado: 0 = sin efecto, 1 = recupera todo el comportamiento limpio.

python
# Continúa los bloques anteriores (usa `model` y `first_token`).
import itertools
import torch
import plotly.graph_objects as go

CANDIDATES = [("Chile", " Santiago"), ("Perú", " Lima"), ("Colombia", " Bogotá"),
              ("Uruguay", " Montevideo"), ("Paraguay", " Asunción"), ("Ecuador", " Quito"),
              ("Venezuela", " Caracas"), ("Argentina", " Buenos"), ("Honduras", " Tegucigalpa")]
TEMPLATE = "La capital de {} es"


def n_tokens(s: str) -> int:
    return len(model.tokenizer.encode(s, add_special_tokens=False))


# El patching por posición exige pares con el MISMO número de tokens
pairs = []
for (c1, a1), (c2, a2) in itertools.permutations(CANDIDATES, 2):
    clean, corrupt = TEMPLATE.format(c1), TEMPLATE.format(c2)
    if n_tokens(clean) == n_tokens(corrupt) and first_token(a1) != first_token(a2):
        pairs.append((clean, corrupt, first_token(a1), first_token(a2)))
print(f"{len(pairs)} pares válidos; ejemplo: {pairs[0][:2]}")
clean, corrupt, t_clean, t_corrupt = pairs[0]


def logit_diff(last_logits: torch.Tensor) -> float:
    return (last_logits[0, t_clean] - last_logits[0, t_corrupt]).float().item()


def patch_sweep(component: str) -> torch.Tensor:
    """component: 'layers_output' (residual), 'attentions_output' o 'mlps_output'."""
    L = model.num_layers
    with model.trace(clean):
        clean_acts = [getattr(model, component)[l].save() for l in range(L)]
        clean_last = model.logits[:, -1, :].save()
    with model.trace(corrupt):
        corrupt_last = model.logits[:, -1, :].save()
    ld_clean, ld_corrupt = logit_diff(clean_last), logit_diff(corrupt_last)

    seq_len = clean_acts[0].shape[1]
    recovered = torch.zeros(L, seq_len)
    for layer in range(L):
        for pos in range(seq_len):
            with model.trace(corrupt):
                h = getattr(model, component)[layer].clone()
                h[:, pos, :] = clean_acts[layer][:, pos, :]
                getattr(model, component)[layer] = h        # escribir la activación parchada
                patched_last = model.logits[:, -1, :].save()
            recovered[layer, pos] = (logit_diff(patched_last) - ld_corrupt) / (ld_clean - ld_corrupt)
    return recovered


ids = model.tokenizer(clean, add_special_tokens=False)["input_ids"]
x_labels = [f"{i}:{model.tokenizer.decode(t)}" for i, t in enumerate(ids)]
results = {}
for comp in ["layers_output", "attentions_output", "mlps_output"]:
    results[comp] = patch_sweep(comp)
    fig = go.Figure(go.Heatmap(z=results[comp].tolist(), x=x_labels,
                               y=list(range(model.num_layers)), colorscale="RdBu", zmid=0))
    fig.update_layout(title=f"Patching {comp}: {clean} vs {corrupt}", yaxis_title="capa")
    fig.write_html(f"patching_{comp}.html")
torch.save(results, "patching_results.pt")

Patrón típico en recall factual (el mismo que encontró ROME en GPT): en el residual la información vive primero en la posición del sujeto ("Chile") durante las capas tempranas y medias, y luego "se mueve" a la última posición; los MLPs de capas medias sobre el sujeto concentran el efecto y la atención de capas medias-tardías en la última posición es la que copia el atributo hacia la predicción.

Ángulo LatamGPT: corre el mismo barrido sobre el checkpoint base y sobre el de continual pretraining en español. Si el pico en el sujeto se desplaza de capa o se vuelve más nítido en es/pt, tienes evidencia mecanicista de qué cambió, no solo una diferencia de accuracy. Repite en portugués con "A capital do {} é" (filtrando de nuevo por longitud en tokens).

5. Attribution patching: todos los parches con un gradiente

El patching exacto cuesta un forward por (capa, posición, componente). Attribution patching lo aproxima con una expansión de Taylor de primer orden: efecto ≈ (actlimpio − actcorrupto) · ∂métrica/∂act, evaluado en el run corrupto. Un forward y un backward dan la estimación para todas las capas y posiciones a la vez, lo que lo vuelve viable en modelos grandes y prompts largos.

python
# Continúa el bloque anterior (usa model, clean, corrupt, t_clean, t_corrupt,
# logit_diff y results).
import torch
from scipy.stats import spearmanr

L = model.num_layers
with model.trace(clean):
    clean_acts = [model.layers_output[l].save() for l in range(L)]
    clean_last = model.logits[:, -1, :].save()

with model.trace(corrupt):
    corrupt_acts = [model.layers_output[l].save() for l in range(L)]
    last = model.logits[:, -1, :]               # una sola lectura de los logits
    corrupt_last = last.save()
    metric = last[0, t_clean] - last[0, t_corrupt]
    with metric.backward():
        # En el backward los gradientes llegan en orden INVERSO al forward
        grads = {l: corrupt_acts[l].grad.save() for l in reversed(range(L))}

ld_clean, ld_corrupt = logit_diff(clean_last), logit_diff(corrupt_last)
attr = torch.zeros(L, clean_acts[0].shape[1])
for l in range(L):
    delta = (clean_acts[l] - corrupt_acts[l]).float()               # (1, seq, d)
    attr[l] = (delta * grads[l].float()).sum(-1)[0].cpu() / (ld_clean - ld_corrupt)

exact = results["layers_output"]
rho = spearmanr(attr.flatten().numpy(), exact.flatten().numpy()).statistic
print(f"Spearman(attribution, patching exacto) en el residual = {rho:.2f}")
MétodoCosto (Qwen3-1.7B, 28 capas, ~6 tokens)Cuándo falla
Activation patching exacto~170 forwards por componentePrácticamente nunca (es la definición del efecto), pero no escala a prompts largos
Attribution patching1 forward + 1 backwardActivaciones con efecto muy no lineal: residual de capas tempranas y parches sobre el sujeto; ahí se subestima
Uso recomendado: attribution patching para filtrar (encontrar las 20-50 ubicaciones candidatas en un barrido grande) y patching exacto para confirmar. El backward calcula también gradientes de los pesos: con 1.7B en bf16 suma ~3.4 GB a la memoria, holgado en 16 GB.

6. Steering con DiffMean: idioma y registro

Un steering vector es una dirección que se suma al residual stream durante la inferencia. La receta más simple y robusta es DiffMean (nombre que usa AxBench para la idea de CAA): promedio de activaciones sobre ejemplos con el concepto menos el promedio sobre ejemplos sin él. Construimos dos vectores útiles para un modelo latinoamericano:

VectorDatos contrastivosUso
portugués − español200 oraciones paralelas de FLORES+ (por_Latn vs spa_Latn, split dev)Diagnosticar y corregir code-switching; medir qué tan lineal es el idioma en el modelo
formal − informalPares mínimos usted / tú (extensible a vos)Controlar el registro sin reentrenar ni cambiar el prompt de sistema
python
# Continúa la sección 2 (usa `model`, `MODEL_ID`, `DEVICE` y `DTYPE`).
import torch
from datasets import load_dataset

N = 200
es = load_dataset("openlanguagedata/flores_plus", "spa_Latn", split="dev").sort("id")
pt = load_dataset("openlanguagedata/flores_plus", "por_Latn", split="dev").sort("id")


def mean_acts(texts: list[str]) -> torch.Tensor:
    """Promedio sobre tokens y ejemplos del residual de cada capa -> (n_capas, d)."""
    total = None
    for t in texts:
        with model.trace(t):
            h = torch.stack([model.layers_output[l][0].mean(0)
                             for l in range(model.num_layers)]).save()
        h = h.detach().float().cpu()
        total = h if total is None else total + h
    return total / len(texts)


v_pt = mean_acts(pt["text"][:N]) - mean_acts(es["text"][:N])

FORMAL = ["¿Usted quiere un café?", "Usted tiene que firmar aquí.", "¿Cómo está usted hoy?",
          "Le agradezco que haya venido.", "¿Usted sabe dónde queda la estación?",
          "Por favor, siéntese y espere su turno."]
INFORMAL = ["¿Tú quieres un café?", "Tú tienes que firmar aquí.", "¿Cómo estás tú hoy?",
            "Te agradezco que hayas venido.", "¿Tú sabes dónde queda la estación?",
            "Por favor, siéntate y espera tu turno."]   # usa 100+ pares en serio
v_formal = mean_acts(FORMAL) - mean_acts(INFORMAL)

torch.save({"model": MODEL_ID, "pt_minus_es": v_pt, "formal_minus_informal": v_formal},
           "steering_vectors.pt")

# Prueba rápida con nnterp: ¿cambia el siguiente token al sumar el vector en la capa 14?
LAYER = 14
with model.trace("Hoy en la mañana fuimos al mercado y compramos"):
    model.steer(layers=LAYER, steering_vector=v_pt[LAYER].to(DEVICE, DTYPE), factor=4.0)
    nxt = model.next_token_probs.save()
print([model.tokenizer.decode(t) for t in nxt[0].topk(8).indices.tolist()])
Generación con steering y evaluación

Para generar texto aplicamos el vector con un forward_hook de PyTorch sobre el modelo HF: no depende de la versión de nnsight y es el mismo mecanismo que usarías en un servicio (EasySteer lo lleva a vLLM). Barremos capa y coeficiente α y medimos tres cosas: % de salidas en portugués según fastText LID, perplejidad de la salida bajo el modelo sin steering (fluidez) y una inspección manual o con juez.

python
import statistics
import fasttext                       # paquete fasttext-numpy2 (compatible con NumPy 2)
import pandas as pd
import torch
from huggingface_hub import hf_hub_download
from transformers import AutoModelForCausalLM, AutoTokenizer

vecs = torch.load("steering_vectors.pt")
MODEL_ID = vecs["model"]
tok = AutoTokenizer.from_pretrained(MODEL_ID)
lm = AutoModelForCausalLM.from_pretrained(MODEL_ID, dtype=torch.bfloat16, device_map="auto").eval()
lid = fasttext.load_model(hf_hub_download("facebook/fasttext-language-identification", "model.bin"))

PROMPTS = ["Cuando llegamos a Valparaíso, lo primero que vimos fue",
           "La mejor forma de aprender a programar es",
           "Mi abuela siempre decía que la cocina",
           "El partido del domingo terminó con",
           "Para preparar unas buenas empanadas hay que"]


def add_steering(layer: int, vec: torch.Tensor, alpha: float):
    v = (alpha * vec).to(lm.device, lm.dtype)

    def hook(module, args, output):
        # En transformers v5 las capas decoder devuelven un tensor; v4 devolvía una tupla
        if isinstance(output, tuple):
            return (output[0] + v,) + tuple(output[1:])
        return output + v

    return lm.model.layers[layer].register_forward_hook(hook)


@torch.no_grad()
def generate(prompt: str, max_new_tokens: int = 40) -> str:
    enc = tok(prompt, return_tensors="pt").to(lm.device)
    out = lm.generate(**enc, max_new_tokens=max_new_tokens, do_sample=False)
    return tok.decode(out[0, enc["input_ids"].shape[1]:], skip_special_tokens=True)


@torch.no_grad()
def perplexity(prompt: str, continuation: str) -> float:
    full = tok(prompt + continuation, return_tensors="pt").to(lm.device)
    labels = full["input_ids"].clone()
    labels[:, : len(tok(prompt)["input_ids"])] = -100      # solo la continuación
    return torch.exp(lm(**full, labels=labels).loss).item()


def lang_of(text: str) -> str:
    labels, _ = lid.predict(text.replace("\n", " "), k=1)
    return labels[0].replace("__label__", "")              # p. ej. "spa_Latn", "por_Latn"


vec = vecs["pt_minus_es"]
rows = []
for layer in [6, 10, 14, 18, 22]:
    for alpha in [0.0, 1.0, 2.0, 4.0]:
        handle = add_steering(layer, vec[layer], alpha)
        try:
            outs = [generate(p) for p in PROMPTS]
        finally:
            handle.remove()                                 # nunca dejes un hook colgado
        ppls = [perplexity(p, o) for p, o in zip(PROMPTS, outs) if o.strip()]
        rows.append({"layer": layer, "alpha": alpha,
                     "pct_pt": sum(lang_of(o) == "por_Latn" for o in outs) / len(outs),
                     "ppl": statistics.median(ppls) if ppls else float("nan"),
                     "ejemplo": outs[0][:80]})

df = pd.DataFrame(rows)
df.to_csv("steering_sweep.csv", index=False)
print(df.to_string())
Lo que vas a verInterpretación
α pequeño, cualquier capaSin cambio de idioma: el vector es chico respecto de la norma del residual
Capas medias, α intermedioZona útil: la salida pasa a portugués y la perplejidad sube poco
Capas tempranas o α grandeTexto degenerado (repeticiones, mezcla de idiomas): % pt alto pero perplejidad disparada
Capas finalesAfecta pocos tokens o solo el primero: el idioma ya se decidió antes
Steering no es gratis ni siempre la mejor opción. Su efecto varía mucho entre inputs y conceptos, y en AxBench una instrucción en el prompt superó a todos los métodos de steering para controlar conceptos. Úsalo como herramienta de diagnóstico (¿el idioma o el registro son lineales? ¿en qué capa?) y como control barato cuando no puedes tocar el prompt; reporta siempre el control "solo prompt" junto al steering. CLaS-Bench (2026) ofrece una evaluación sistemática de steering de idioma.

8. Escalar a 70B y migrar de versión

Con nnsight el mismo código corre en remoto sobre NDIF (National Deep Inference Fabric): el modelo vive en sus servidores y tu intervención se ejecuta ahí, sin GPU local. Requiere una API key gratuita y que el modelo esté disponible en ese momento (revisa la página de estado de NDIF).

python
from nnsight import CONFIG
from nnterp import StandardizedTransformer
from nnterp.interventions import logit_lens

CONFIG.set_default_api_key("TU_API_KEY_DE_NDIF")

# Elige un modelo que figure como disponible en el estado de NDIF; los gated exigen
# haber aceptado la licencia en HF con la misma cuenta.
big = StandardizedTransformer("meta-llama/Llama-3.1-70B", remote=True)
probs = logit_lens(big, ["La capital de Chile es", "A capital do Chile é"], remote=True)
santiago = big.tokenizer.encode(" Santiago", add_special_tokens=False)[0]
print(probs[:, :, santiago])        # P(" Santiago") por capa en 70B

# Dentro de un trace remoto, igual que en local:
with big.trace("La capital de Chile es", remote=True):
    mid = big.layers_output[big.num_layers // 2][0, -1].save()
print(mid.shape)
