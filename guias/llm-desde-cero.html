Un LLM moderno desde cero en PyTorch

Implementar pieza por pieza el decoder que comparten Llama 3, Qwen3, OLMo 2 y SmolLM3 (RMSNorm, RoPE, GQA, SwiGLU, QK-norm), entrenar un modelo de ~100M parámetros sobre FineWeb-2 en español y portugués, hacer ablaciones baratas y exportarlo a Qwen3ForCausalLM para evaluarlo con lm-eval-harness y servirlo con el ecosistema de Hugging Face.

2. Anatomía de un decoder en 2026

Entre 2023 y 2026 los decoders densos abiertos convergieron en una receta muy parecida. Las diferencias reales están en la normalización, en cómo se codifica la posición y en el tamaño del vocabulario. Los modelos frontera de 2026 agregan MoE y atención híbrida o sparse encima de este mismo bloque (ver MoE desde cero), así que entender el decoder denso sigue siendo el punto de partida.

Por qué cada decisión:

  • Pre-norm con RMSNorm: el residual queda limpio de normalizaciones, lo que estabiliza modelos profundos; RMSNorm es más barata que LayerNorm (no centra) y rinde igual.
  • RoPE: codifica posición rotando pares de dimensiones de q y k, así que el producto q·k depende solo de la distancia relativa. Es lo que después permite extender contexto con ABF/YaRN.
  • GQA: varias cabezas de query comparten una cabeza de K/V. Con 12 cabezas de query y 4 de K/V el KV cache baja 3× casi sin pérdida de calidad, algo crítico al servir.
  • SwiGLU con dimensión oculta ≈ 8/3·d: tres matrices en vez de dos, mismo costo que un MLP 4·d y mejor loss.
  • QK-norm (RMSNorm por cabeza sobre q y k): evita el crecimiento descontrolado de los logits de atención, una de las causas de divergencia a LR alto (Wortsman et al., 2023).
  • Sin biases y con weight tying: los biases no aportan; en modelos chicos el embedding es una fracción grande de los parámetros y compartirlo con lm_head ahorra ~25M en nuestro caso.

3. Datos: FineWeb-2 es/pt a shards binarios

Usamos HuggingFaceFW/fineweb-2 (no requiere aceptar licencia), con los configs spa_Latn y por_Latn, mezclados 80/20. El tokenizer es un BPE byte-level es/pt entrenado como en la guía Entrenar un tokenizador, pero con vocab_size=32_768: a 100M parámetros un vocabulario de 64K o más se come demasiado presupuesto en el embedding. Con menos de 65.536 tokens cada id cabe en uint16 y el corpus completo ocupa 2 bytes por token.

Cada documento termina en EOS y se concatena al siguiente: así no se desperdicia ni un token en padding. La validación sale del split test de cada idioma por separado, para medir bits-per-byte en español y en portugués de forma independiente.

python
# prepare_data.py — FineWeb-2 (es 80% / pt 20%) → data/train.bin, data/val_es.bin, data/val_pt.bin
import json
from itertools import chain
from pathlib import Path

import numpy as np
from datasets import interleave_datasets, load_dataset
from transformers import AutoTokenizer

TOKENIZER = "latamgpt-tokenizer-32k"   # salida de la guía tokenizer-training con vocab_size=32_768
TRAIN_TOKENS = 2_500_000_000
VAL_TOKENS = 5_000_000                 # por idioma
OUT = Path("data")
OUT.mkdir(exist_ok=True)

tok = AutoTokenizer.from_pretrained(TOKENIZER)
assert len(tok) <= 65_536, "el vocabulario no cabe en uint16"
EOS = tok.eos_token_id


def fineweb2(lang: str, split: str):
    ds = load_dataset("HuggingFaceFW/fineweb-2", name=lang, split=split, streaming=True)
    return ds.select_columns(["text"])


def write_stream(ds, path: Path, max_tokens: int, batch_docs: int = 1000) -> dict:
    """Tokeniza en batches, agrega EOS por documento y escribe uint16 en disco."""
    n_tokens, n_bytes = 0, 0
    with open(path, "wb") as f:
        for batch in ds.iter(batch_size=batch_docs):
            texts = batch["text"]
            ids = tok(texts, add_special_tokens=False)["input_ids"]   # sin BOS: el separador es EOS
            arr = np.fromiter(chain.from_iterable(d + [EOS] for d in ids), dtype=np.uint16)
            arr.tofile(f)
            n_tokens += arr.size
            n_bytes += sum(len(t.encode("utf-8")) for t in texts)
            if n_tokens >= max_tokens:
                break
    print(f"{path.name}: {n_tokens:,} tokens · {n_bytes / n_tokens:.2f} bytes/token")
    return {"tokens": n_tokens, "bytes_per_token": n_bytes / n_tokens}


meta = {
    "eos_id": EOS,
    "vocab_size": len(tok),
    "val_es": write_stream(fineweb2("spa_Latn", "test"), OUT / "val_es.bin", VAL_TOKENS),
    "val_pt": write_stream(fineweb2("por_Latn", "test"), OUT / "val_pt.bin", VAL_TOKENS),
}
mix = interleave_datasets(
    [fineweb2("spa_Latn", "train"), fineweb2("por_Latn", "train")],
    probabilities=[0.8, 0.2],
    seed=42,
)
meta["train"] = write_stream(mix, OUT / "train.bin", TRAIN_TOKENS)
(OUT / "meta.json").write_text(json.dumps(meta, indent=2))
Bytes por token como métrica de tokenizer: el script imprime cuántos bytes UTF-8 cubre cada token en español y en portugués. Un tokenizer es/pt bien entrenado cubre bastantes más bytes por token que uno pensado para inglés, y eso se traduce directamente en más texto visto por el mismo cómputo. Guardamos el valor en meta.json porque lo necesitamos para calcular bits-per-byte.
Tiempo y disco: tokenizar 2.5B tokens en un solo proceso toma del orden de una hora (los tokenizers rápidos paralelizan cada batch en varios hilos) y train.bin pesa ~5 GB. Si tu corpus ya está filtrado (por ejemplo con FineWeb-Edu o JQL), cambia solo la función fineweb2.

4. El modelo pieza por pieza

Todo el modelo vive en model.py. Lo partimos en dos bloques para comentarlo; el segundo continúa el primero en el mismo archivo. Los nombres (embed_tokens, layers.i.self_attn.q_proj, q_norm, mlp.gate_proj, input_layernorm...) replican los de Qwen3 en transformers a propósito.

# model.py (parte 1 de 2)
import math
from dataclasses import dataclass

import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.nn.attention.flex_attention import flex_attention


@dataclass
class ModelConfig:
    vocab_size: int = 32_768
    d_model: int = 768
    n_layers: int = 12
    n_heads: int = 12
    n_kv_heads: int = 4          # GQA: 3 cabezas de query por cabeza K/V
    head_dim: int = 64
    d_ff: int = 2048             # ≈ 8/3 · d_model, redondeado a múltiplo de 256
    max_seq_len: int = 2048
    rope_theta: float = 10_000.0
    norm_eps: float = 1e-6
    qk_norm: bool = True
    gated_attn: bool = False     # ablación: gate sigmoide después de SDPA
    nope_every: int = 0          # ablación: 4 = sin RoPE en una de cada 4 capas (estilo SmolLM3)
    tie_embeddings: bool = True
    z_loss: float = 0.0          # ablación: OLMo 2 usa 1e-5


def rotate_half(x: torch.Tensor) -> torch.Tensor:
    # Convención "rotate_half" de Llama/Qwen: pares (i, i + d/2), no (2i, 2i + 1)
    x1, x2 = x.chunk(2, dim=-1)
    return torch.cat((-x2, x1), dim=-1)


class Rotary(nn.Module):
    def __init__(self, head_dim: int, max_seq_len: int, theta: float):
        super().__init__()
        inv_freq = 1.0 / (theta ** (torch.arange(0, head_dim, 2, dtype=torch.float) / head_dim))
        freqs = torch.outer(torch.arange(max_seq_len, dtype=torch.float), inv_freq)
        emb = torch.cat((freqs, freqs), dim=-1)            # [T, head_dim]
        self.register_buffer("cos", emb.cos(), persistent=False)
        self.register_buffer("sin", emb.sin(), persistent=False)

    def forward(self, x: torch.Tensor) -> torch.Tensor:  # x: [B, H, T, D]
        T = x.shape[-2]
        cos, sin = self.cos[:T].to(x.dtype), self.sin[:T].to(x.dtype)
        return x * cos + rotate_half(x) * sin


class SwiGLU(nn.Module):
    def __init__(self, cfg: ModelConfig):
        super().__init__()
        self.gate_proj = nn.Linear(cfg.d_model, cfg.d_ff, bias=False)
        self.up_proj = nn.Linear(cfg.d_model, cfg.d_ff, bias=False)
        self.down_proj = nn.Linear(cfg.d_ff, cfg.d_model, bias=False)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.down_proj(F.silu(self.gate_proj(x)) * self.up_proj(x))
Atención GQA con QK-norm, bloque y modelo completo
python
# model.py (parte 2 de 2): continúa el bloque anterior en el mismo archivo
class Attention(nn.Module):
    def __init__(self, cfg: ModelConfig, layer_idx: int):
        super().__init__()
        self.cfg = cfg
        self.n_heads, self.n_kv, self.hd = cfg.n_heads, cfg.n_kv_heads, cfg.head_dim
        self.q_proj = nn.Linear(cfg.d_model, self.n_heads * self.hd, bias=False)
        self.k_proj = nn.Linear(cfg.d_model, self.n_kv * self.hd, bias=False)
        self.v_proj = nn.Linear(cfg.d_model, self.n_kv * self.hd, bias=False)
        self.o_proj = nn.Linear(self.n_heads * self.hd, cfg.d_model, bias=False)
        if cfg.qk_norm:
            # Igual que Qwen3: RMSNorm sobre head_dim, por cabeza (OLMo 2 normaliza la proyección completa)
            self.q_norm = nn.RMSNorm(self.hd, eps=cfg.norm_eps)
            self.k_norm = nn.RMSNorm(self.hd, eps=cfg.norm_eps)
        self.use_rope = not (cfg.nope_every and (layer_idx + 1) % cfg.nope_every == 0)
        self.gate = nn.Linear(cfg.d_model, self.n_heads * self.hd, bias=False) if cfg.gated_attn else None

    def qkv(self, x: torch.Tensor, rope: Rotary):
        B, T, _ = x.shape
        q = self.q_proj(x).view(B, T, self.n_heads, self.hd)
        k = self.k_proj(x).view(B, T, self.n_kv, self.hd)
        v = self.v_proj(x).view(B, T, self.n_kv, self.hd).transpose(1, 2)
        if self.cfg.qk_norm:
            q, k = self.q_norm(q), self.k_norm(k)        # QK-norm antes de RoPE
        q, k = q.transpose(1, 2), k.transpose(1, 2)      # [B, H, T, D]
        if self.use_rope:
            q, k = rope(q), rope(k)
        return q, k, v

    def forward(self, x, rope, block_mask=None):
        B, T, _ = x.shape
        q, k, v = self.qkv(x, rope)
        if block_mask is None:
            # enable_gqa=True: SDPA reparte las 4 cabezas K/V entre las 12 de query sin repeat_interleave
            y = F.scaled_dot_product_attention(q, k, v, is_causal=True, enable_gqa=True)
        else:
            y = flex_attention(q, k, v, block_mask=block_mask, enable_gqa=True)
        y = y.transpose(1, 2).reshape(B, T, self.n_heads * self.hd)
        if self.gate is not None:
            y = y * torch.sigmoid(self.gate(x))          # gated attention (Qiu et al., 2025)
        return self.o_proj(y)


class Block(nn.Module):
    def __init__(self, cfg: ModelConfig, layer_idx: int):
        super().__init__()
        self.input_layernorm = nn.RMSNorm(cfg.d_model, eps=cfg.norm_eps)
        self.self_attn = Attention(cfg, layer_idx)
        self.post_attention_layernorm = nn.RMSNorm(cfg.d_model, eps=cfg.norm_eps)
        self.mlp = SwiGLU(cfg)

    def forward(self, x, rope, block_mask=None):
        x = x + self.self_attn(self.input_layernorm(x), rope, block_mask)   # pre-norm
        x = x + self.mlp(self.post_attention_layernorm(x))
        return x


class LLM(nn.Module):
    def __init__(self, cfg: ModelConfig):
        super().__init__()
        self.cfg = cfg
        self.embed_tokens = nn.Embedding(cfg.vocab_size, cfg.d_model)
        self.layers = nn.ModuleList([Block(cfg, i) for i in range(cfg.n_layers)])
        self.norm = nn.RMSNorm(cfg.d_model, eps=cfg.norm_eps)
        self.lm_head = nn.Linear(cfg.d_model, cfg.vocab_size, bias=False)
        if cfg.tie_embeddings:
            self.lm_head.weight = self.embed_tokens.weight
        self.rope = Rotary(cfg.head_dim, cfg.max_seq_len, cfg.rope_theta)
        self.apply(self._init_weights)
        # Proyecciones que escriben en el residual: std reducida por profundidad (estilo GPT-2)
        for name, p in self.named_parameters():
            if name.endswith(("o_proj.weight", "down_proj.weight")):
                nn.init.normal_(p, mean=0.0, std=0.02 / math.sqrt(2 * cfg.n_layers))

    @staticmethod
    def _init_weights(m: nn.Module):
        if isinstance(m, (nn.Linear, nn.Embedding)):
            nn.init.normal_(m.weight, mean=0.0, std=0.02)

    def forward(self, idx, targets=None, block_mask=None):
        x = self.embed_tokens(idx)
        for layer in self.layers:
            x = layer(x, self.rope, block_mask)
        logits = self.lm_head(self.norm(x)).float()
        if targets is None:
            return logits, None, None
        ce = F.cross_entropy(logits.view(-1, logits.size(-1)), targets.view(-1))
        loss = ce
        if self.cfg.z_loss > 0:
            # z-loss: penaliza log Z grande para que los logits de salida no deriven
            loss = ce + self.cfg.z_loss * torch.logsumexp(logits, dim=-1).pow(2).mean()
        return logits, loss, ce.detach()


if __name__ == "__main__":
    model = LLM(ModelConfig())
    n = sum(p.numel() for p in model.parameters())
    n_emb = model.embed_tokens.weight.numel()
    print(f"{n / 1e6:.1f}M parámetros ({(n - n_emb) / 1e6:.1f}M sin embeddings)")   # ~100.7M (~75.5M)
Cuenta de parámetros: por capa, la atención GQA suma 768·(768 + 256 + 256 + 768) ≈ 1.57M y el SwiGLU 3·768·2048 ≈ 4.72M; por 12 capas son ~75.5M. El embedding de 32.768 × 768 agrega ~25.2M, compartido con lm_head. Sin tying serían ~126M: en modelos chicos la decisión de vocabulario pesa tanto como la profundidad.

5. Máscara intra-documento con FlexAttention

Con documentos concatenados, una ventana de 2048 tokens suele contener el final de un artículo de noticias argentino y el comienzo de un foro brasileño. Con la máscara causal simple, los tokens del segundo documento atienden al primero. Llama 3 y SmolLM3 enmascaran entre documentos (la condición es causal y mismo documento). FlexAttention permite expresarlo como una función de Python que se compila a un kernel con bloques dispersos: los bloques completamente enmascarados ni siquiera se calculan.

python
# masks.py
import torch
from torch.nn.attention.flex_attention import create_block_mask


def doc_ids_from_eos(x: torch.Tensor, eos_id: int) -> torch.Tensor:
    """[B, T] → id de documento por posición. El EOS pertenece al documento que cierra."""
    is_eos = (x == eos_id).int()
    return is_eos.cumsum(dim=1) - is_eos


def document_block_mask(doc_ids: torch.Tensor):
    B, T = doc_ids.shape

    def mask_mod(b, h, q_idx, kv_idx):
        causal = q_idx >= kv_idx
        same_doc = doc_ids[b, q_idx] == doc_ids[b, kv_idx]
        return causal & same_doc

    # H=None: la misma máscara para todas las cabezas
    return create_block_mask(mask_mod, B=B, H=None, Q_LEN=T, KV_LEN=T, device=doc_ids.device)
¿Y las posiciones? No hace falta reiniciar los position ids por documento: RoPE solo ve distancias relativas, y dentro de un documento las distancias son las mismas empiece donde empiece. Lo que cambia con la máscara es que el modelo deja de aprender a "leer" texto ajeno como contexto, algo que importa más al entrenar con contexto largo.
FlexAttention necesita torch.compile: en modo eager cae a una implementación de referencia lenta y que usa mucha memoria. En train.py compilamos el modelo entero, así que la llamada a flex_attention queda dentro del grafo compilado. La máscara se recalcula en cada micro-batch; con B=8 y T=2048 el costo es despreciable frente al forward.

6. Loop de entrenamiento

Receta estándar de 2025-2026 para modelos chicos: autocast bf16 con pesos fp32, AdamW con β2=0.95 y weight decay 0.1 solo en matrices (no en normas ni embeddings), clipping a 1.0 y schedule WSD (warmup, plateau y decay lineal a cero) en vez de coseno. WSD tiene una ventaja práctica: puedes ramificar un cooldown desde cualquier checkpoint del plateau y obtener un modelo "terminado" sin reentrenar, la base de las scaling laws baratas (ver la guía Reproducir una scaling law).

Logueamos la cross-entropy en bits-per-byte (bpb) por idioma: a diferencia de la loss por token, el bpb es comparable entre tokenizers distintos, y es la métrica honesta para decidir si un tokenizer es/pt ayuda. Cada 250 pasos medimos además el logit máximo de atención por capa: si crece sin control, la corrida está a punto de divergir.

    vocab_size=meta["vocab_size"], max_seq_len=args.seq_len, qk_norm=not args.no_qk_norm,
    z_loss=args.z_loss, nope_every=args.nope_every, gated_attn=args.gated_attn,
)
raw_model = LLM(cfg).to(device)
model = torch.compile(raw_model)

# --- Datos: ventanas aleatorias sobre el memmap; generador propio para que todas
#     las ablaciones vean exactamente los mismos batches aunque el init consuma RNG distinto
data = {s: np.memmap(f"data/{s}.bin", dtype=np.uint16, mode="r") for s in ("train", "val_es", "val_pt")}
gen = torch.Generator().manual_seed(args.seed)


def get_batch(split: str, bs: int):
    arr, T = data[split], args.seq_len
    ix = torch.randint(len(arr) - T - 1, (bs,), generator=gen).tolist()
    xy = torch.stack([torch.from_numpy(arr[i:i + T + 1].astype(np.int64)) for i in ix])
    xy = xy.pin_memory().to(device, non_blocking=True)
    return xy[:, :-1], xy[:, 1:]


# --- Optimizador: weight decay solo en matrices 2D que no sean el embedding
decay, no_decay = [], []
for name, prm in raw_model.named_parameters():
    (decay if prm.dim() == 2 and "embed_tokens" not in name else no_decay).append(prm)
opt = torch.optim.AdamW(
    [{"params": decay, "weight_decay": 0.1}, {"params": no_decay, "weight_decay": 0.0}],
    lr=args.lr, betas=(0.9, 0.95), eps=1e-8, fused=True,
)
sched = get_wsd_schedule(
    opt, num_warmup_steps=int(0.02 * args.steps), num_decay_steps=int(0.2 * args.steps),
    num_training_steps=args.steps, decay_type="linear", min_lr_ratio=0.0,
)


@torch.no_grad()
def evaluate(n_batches: int = 20) -> dict:
    model.eval()
    out = {}
    for split in ("val_es", "val_pt"):
        losses = []
        for _ in range(n_batches):
            x, y = get_batch(split, args.micro_batch)
            with torch.autocast("cuda", dtype=torch.bfloat16):
                _, _, ce = model(x, y)
            losses.append(ce.item())
        ce = sum(losses) / len(losses)
        out[f"{split}/loss"] = ce
        out[f"{split}/bpb"] = ce / math.log(2) / meta[split]["bytes_per_token"]
    model.train()
    return out


@torch.no_grad()
def max_attn_logits(x: torch.Tensor) -> list[float]:
    """Logit máximo q·k/√d por capa (modelo sin compilar + hooks); se dispara antes de una divergencia."""
    maxes, hooks = [], []
    for layer in raw_model.layers:
        attn = layer.self_attn

        def hook(mod, inputs, attn=attn):
            q, k, _ = attn.qkv(inputs[0], raw_model.rope)
            k = k.repeat_interleave(q.shape[1] // k.shape[1], dim=1)
            maxes.append(((q @ k.transpose(-2, -1)) * q.shape[-1] ** -0.5).max().item())

        hooks.append(attn.register_forward_pre_hook(hook))
    with torch.autocast("cuda", dtype=torch.bfloat16):
        raw_model(x)
    for h in hooks:
        h.remove()
    return maxes


wandb.init(project="llm-desde-cero-es-pt", name=args.run_name, config={**asdict(cfg), **vars(args)})
ckpt_dir = Path("runs") / args.run_name
ckpt_dir.mkdir(parents=True, exist_ok=True)
tokens_per_step = args.micro_batch * args.accum * args.seq_len

for step in range(args.steps):
    t0 = time.time()
    for _ in range(args.accum):
        x, y = get_batch("train", args.micro_batch)
        bm = document_block_mask(doc_ids_from_eos(x, EOS)) if args.doc_mask else None
        with torch.autocast("cuda", dtype=torch.bfloat16):
            _, loss, ce = model(x, y, bm)
        (loss / args.accum).backward()
    grad_norm = torch.nn.utils.clip_grad_norm_(raw_model.parameters(), 1.0)   # devuelve la norma previa al clip
    opt.step()
    sched.step()
    opt.zero_grad(set_to_none=True)

    if step % 10 == 0:
        torch.cuda.synchronize()
        log = {"train/loss": ce.item(), "train/grad_norm": grad_norm.item(),
               "lr": sched.get_last_lr()[0], "tokens_per_s": tokens_per_step / (time.time() - t0)}
        if step % 250 == 0 or step == args.steps - 1:
            log.update(evaluate())
            logits_max = max_attn_logits(x[:1, :512])
            log.update({f"attn_logit_max/layer_{i}": v for i, v in enumerate(logits_max)})
        wandb.log(log, step=step)
        print(f"step {step} | loss {log['train/loss']:.3f} | gnorm {log['train/grad_norm']:.2f} "
              f"| {log['tokens_per_s']:,.0f} tok/s")
    if (step + 1) % 1000 == 0 or step == args.steps - 1:
        torch.save({"model": raw_model.state_dict(), "cfg": asdict(cfg), "step": step + 1},
                   ckpt_dir / "ckpt.pt")

7. Ablaciones rápidas con la misma semilla

La gracia de tener un modelo propio de 100M es poder responder preguntas de arquitectura con evidencia en horas. Todas las variantes usan la misma semilla de datos y el mismo número de pasos, así que las curvas son directamente comparables. Con un decay corto al final (WSD), 2000 pasos alcanzan para ver diferencias relativas.

LR 3× con y sin QK-norm¿Cuánto margen de LR compra QK-norm?Sin QK-norm los logits de atención crecen y la loss diverge a LR alto; con QK-norm la sensibilidad al LR baja (Wortsman et al., 2023)
z-loss 1e-5¿Estabiliza los logits de salida sin costo?Mitiga la deriva de log Z a LR alto; OLMo 2 lo usa con coeficiente 1e-5
NoPE cada 4 capas¿Se puede quitar RoPE de algunas capas sin perder calidad?SmolLM3 lo adopta para mejorar contexto largo sin degradar el contexto corto
Gated attention¿Mejora loss y estabilidad un gate sigmoide tras SDPA?Qiu et al. (2025) reportan mejor loss, mayor tolerancia al LR y menos attention sinks; Qwen3-Next lo usa
Máscara por documento¿Importa no atender entre documentos?Efecto chico con contexto corto; más relevante al extender contexto
Ruido entre semillas: a esta escala, diferencias de ~0.01 bpb pueden ser ruido. Antes de concluir, corre la base con 2-3 semillas de inicialización distintas y mira la dispersión; si una ablación no se separa de esa banda, no hay evidencia. Las conclusiones a 100M tampoco se transfieren automáticamente a 7B: úsalas para descartar ideas, no para cerrar decisiones; para extrapolar hace falta una ley de escala con varios tamaños.

8. Exportar a Qwen3ForCausalLM y generar texto

Como replicamos la arquitectura de Qwen3 (QK-norm por cabeza antes de RoPE, rotate_half, SwiGLU, sin biases, pre-norm), la variante base se carga en Qwen3ForCausalLM solo agregando el prefijo model. a los nombres. En transformers v5 la configuración de RoPE va en rope_parameters (config.rope_theta ya no existe). Las variantes con gated attention o NoPE no tienen equivalente en Qwen3 y no se pueden exportar así; la máscara por documento sí, porque solo afecta al entrenamiento.

python
# export_hf.py — runs/base/ckpt.pt → ./export (formato Qwen3, transformers v5)
import torch
from transformers import AutoTokenizer, Qwen3Config, Qwen3ForCausalLM

from model import LLM, ModelConfig

ck = torch.load("runs/base/ckpt.pt", map_location="cpu")
cfg = ModelConfig(**ck["cfg"])
assert cfg.qk_norm and not cfg.gated_attn and cfg.nope_every == 0, "variante no exportable a Qwen3"
ours = LLM(cfg)
ours.load_state_dict(ck["model"])
ours.eval()

tok = AutoTokenizer.from_pretrained("latamgpt-tokenizer-32k")
hf_cfg = Qwen3Config(
    vocab_size=cfg.vocab_size,
    hidden_size=cfg.d_model,
    intermediate_size=cfg.d_ff,
    num_hidden_layers=cfg.n_layers,
    num_attention_heads=cfg.n_heads,
    num_key_value_heads=cfg.n_kv_heads,
    head_dim=cfg.head_dim,
    max_position_embeddings=cfg.max_seq_len,
    rms_norm_eps=cfg.norm_eps,
    tie_word_embeddings=cfg.tie_embeddings,
    rope_parameters={"rope_type": "default", "rope_theta": cfg.rope_theta},
    bos_token_id=tok.bos_token_id,
    eos_token_id=tok.eos_token_id,
    pad_token_id=tok.pad_token_id,
)

missing, unexpected = hf.load_state_dict(sd, strict=False)
assert not unexpected and all(k.startswith("lm_head") for k in missing), (missing, unexpected)

Para comparar el bpb de nuestro modelo con el de Qwen3 (tokenizers distintos), medimos ambos sobre el mismo texto crudo y normalizamos por bytes:

python
# bpb_compare.py — bits-per-byte de cualquier modelo HF sobre FineWeb-2 test (es y pt)
import math

import torch
from datasets import load_dataset
from transformers import AutoModelForCausalLM, AutoTokenizer


@torch.no_grad()
def bits_per_byte(model_id: str, lang: str, n_docs: int = 500, max_len: int = 1024) -> float:
    tok = AutoTokenizer.from_pretrained(model_id)
    model = AutoModelForCausalLM.from_pretrained(model_id, dtype=torch.bfloat16, device_map="cuda").eval()
    ds = load_dataset("HuggingFaceFW/fineweb-2", name=lang, split="test", streaming=True)
    total_nats, total_bytes = 0.0, 0
    for doc in ds.take(n_docs):
        ids = tok(doc["text"], add_special_tokens=False, return_tensors="pt").input_ids[:, :max_len]
        if ids.shape[1] < 2:
            continue
        ids = ids.to(model.device)
        loss = model(input_ids=ids, labels=ids).loss.float().item()   # media sobre ids.shape[1]-1 tokens
        total_nats += loss * (ids.shape[1] - 1)
        # Bytes de los tokens predichos (todos menos el primero), así ambos modelos se miden igual
        total_bytes += len(tok.decode(ids[0, 1:]).encode("utf-8"))
    return total_nats / math.log(2) / total_bytes


for model_id in ["./export", "Qwen/Qwen3-0.6B-Base"]:
    for lang in ["spa_Latn", "por_Latn"]:
        print(f"{model_id:24s} {lang}: {bits_per_byte(model_id, lang):.3f} bpb")
